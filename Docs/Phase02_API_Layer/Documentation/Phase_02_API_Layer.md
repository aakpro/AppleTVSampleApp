## 🗄️ Caching Strategy (`sampletv-api-swift-package`)  

### Hybrid Cache Architecture:
```swift
// Memory Layer (in-process dict - fast) + Disk Layer (Realm/JSON - persistent)
protocol CacheManager {
    func getForKey(key: String) async -> [TVShow]?  
    func cache(for key: TVDiscoveryCacheKey, data: Data) try?
}

// Cache Key Structure
struct TVDiscoveryCacheKey {
    let tvId: Int
    let page: Int
    
    var stringHash: String { "\(tvId)/\(page)" }  
}
```  

### Cache Invalidation Strategy:
- On API key change → Clear all cache (force network refresh)  
- On user action (logout, new login) → Mark cache for invalidation  
- On rate limit exceeded → Return stale + retry with backoff
