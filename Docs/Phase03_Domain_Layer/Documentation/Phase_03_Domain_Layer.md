## 🤲 Clean Architecture Enforcement  

### DOMAIN LAYER RULES (Violation = CI Fail):
1. ✅ NO Network/API imports allowed  
2. ✅ NO Presentation layer dependencies  
3. ✅ ONLY input parameters → output results (pure functions)  
4. ✅ Entity structs must be values, not classes  
5. ✅ `Codable` conformance on all entities  

### Example - Pure Use Case (`GetMoviesBySearchQuery.swift`):
```swift
// MARK: - Domain-Only UseCase Interface (Zero Dependencies!)

protocol GetMoviesUseCaseProtocol {
    func execute(query: String) -> [Movie]  
}

// Implementation - NO external imports, no network calls allowed!
struct GetMoviesImplementation: GetMoviesUseCaseProtocol {
    // Pure Swift function only!
    func execute(query: String) -> [Movie] {  
        return movies.filter { 
            $0.title.lowercased().contains(query.lowercased()) 
        }
    }
}  
```
